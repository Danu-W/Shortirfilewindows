FITUR 02

Fokus pada yang penting.

Lupakan kebiasaan membuka sepuluh aplikasi untuk menemukan satu file. Semua yang kamu butuhkan ada di satu tempat.

Semua info penting, tampil langsung.

Setiap file menampilkan ukuran dan tipe secara jelas, jadi kamu bisa memutuskan lebih cepat—tanpa menebak-nebak.

  • Cari file cepat dengan kata kunci.
  • Lihat ukuran dan tipe file sekilas.
  • Sortir berdasar nama, tanggal, atau ukuran.
  • Pindahkan langsung dari hasil pencarian.
◒
⌘

Momentum, bukan hambatan.

Semakin sedikit langkah, semakin cepat kamu kembali ke pekerjaan yang sebenarnya penting.

  • Antarmuka ringan tanpa gangguan.
  • Semua aksi tersedia dalam satu layar.
  • Hasil langsung terlihat setelah file dipindah.

Rasakan momentumnya.
